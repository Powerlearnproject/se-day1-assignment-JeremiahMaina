#Part 1: Introduction to Software Engineering

Explain what software engineering is and discuss its importance in the technology industry.
 software engineering is the systemic application of methods and engineering principles to development and maintainance of software systems.
 It is useful in the creation of software applications and systems.
Identify and describe at least three key milestones in the evolution of software engineering.
Establishment of software engineering in 1960s.
Innovation of structured programming in the 1970s.
Advent of agile methodologies in 2000s.


List and briefly explain the phases of the Software Development Life Cycle.
Requirements- user and system needs.
Design- creating detailed designs
Implementation- Building the system according to specifications
Testing the system to confirm its quality and functional standards
Deployment- releasing to users 
Maintainance-providing support, enhancement and updates to  the system


Compare and contrast the Waterfall and Agile methodologies. Provide examples of scenarios where each would be appropriate.
 In agile one can make changes while in waterfall no changes can be made.         

Describe the roles and responsibilities of a Software Developer, a Quality Assurance Engineer, and a Project Manager in a software engineering team.
Software developer- used for writing codes
Quality Assurance Engineer-ensures  software quality
Project manager - oversees the planning,delivery and execution of software projects



Discuss the importance of Integrated Development Environments (IDEs) and Version Control Systems (VCS) in the software development process. Give examples of each.
They enhance productivity,collaboration and code quality.
Example of VCS-GIT
Example of IDEs- visual studio

What are some common challenges faced by software engineers? Provide strategies to overcome these challenges.
changing requirements-use of agile methodologies to overcome these
Tight deadlines - regular reassessment of project timelines


Explain the different types of testing (unit, integration, system, and acceptance) and their importance in software quality assurance.
system testing-testing entire software systems
unit testing - testing modules of softwares
integration testing- testing interaction between different subsystems
These types of testing help in identifying and fixing defects early in the development process also they lead to high quality software products
